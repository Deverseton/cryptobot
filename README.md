# 🤖 CryptoBot - Анализатор крипторынка

Полнофункциональная программа на Python для анализа топ-20 криптовалют по капитализации с прогнозом цены на 1 час вперед.

## ✨ Возможности

✅ **Анализ топ-20 криптовалют** по рыночной капитализации
✅ **11+ технических индикаторов:**
- Скользящие средние (MA7, MA14, MA25)
- RSI (Relative Strength Index)
- MACD (Moving Average Convergence Divergence)
- Bollinger Bands
- ATR (Average True Range)
- Стохастик

✅ **Прогноз цены на 1 час вперед:**
- Направление тренда (BULL/BEAR/NEUTRAL)
- Процент уверенности
- Целевые диапазоны цены

✅ **Сбор данных:**
- CoinGecko API для данных о капитализации
- Binance API для OHLCV данных

✅ **Режим мониторинга** - автоматический анализ каждые N минут

## 📋 Требования

- Python 3.8+
- Интернет соединение

## 🚀 Установка и запуск

### 1. Установить зависимости

```bash
pip install -r requirements.txt
```

### 2. Запустить программу

**Один анализ:**
```bash
python crypto_analyzer.py
```

**Режим мониторинга (анализ каждые 30 минут):**
```bash
python crypto_analyzer.py --loop 30
```

**Справка:**
```bash
python crypto_analyzer.py --help
```

## 🎯 Интерпретация сигналов

### 🔼 BULL (РОСТ)
- Цена, вероятно, будет расти в ближайший час
- Хороший момент для покупки
- Уверенность > 70% = сильный сигнал

### 🔽 BEAR (ПАДЕНИЕ)
- Цена, вероятно, будет падать в ближайший час
- Хороший момент для продажи
- Уверенность > 70% = сильный сигнал

### ↔️ NEUTRAL (БОКОВИК)
- Цена будет двигаться боком (без явного тренда)
- Ждите более четких сигналов перед входом

## 📈 Технические индикаторы

### RSI (Relative Strength Index)
- **> 70**: Перекуплено (медвежий сигнал)
- **< 30**: Перепродано (бычий сигнал)
- **30-70**: Нейтральная зона

### MACD
- **Позитивный гистограмма**: Бычий сигнал
- **Негативный гистограмма**: Медвежий сигнал

### Bollinger Bands
- **Цена выше верхней полосы**: Перекуплено
- **Цена ниже нижней полосы**: Перепродано

### Стохастик
- **> 80**: Перекуплено
- **< 20**: Перепродано
